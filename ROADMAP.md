# Roadmap

Phases follow the owner's delivery numbering (which supersedes older numbering in the software plan).

- Phase 0: verified catalog contract, 50 reviewed seeds, source adapters, governance and account readiness.
- Phase 1: monorepo, web, authentication, database, monitor dashboard and provenance.
- Phase 2: safe polling, normalization, dedupe, warning evidence and source health.
- Phase 3: consented daily/weekly digests, mock delivery, suppression, signed webhooks and unsubscribe.
- Phase 3A: mandatory cookieless analytics, authoritative PMF aggregates, admin reports and aggregate-only agent access.
- Phase 4: protected CI/CD, approved Fly provisioning, migration/restore gates, security/load/E2E verification and mock-email web launch.
- Phase 5: tested dormant web/email advertising interfaces only.

Public live email is a separate verified-sender gate. Active advertising, CVE monitoring, paid tiers, customer AI and inventory agents are deferred.
